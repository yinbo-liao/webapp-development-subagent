Incident Response (from Strategy Doc §8.3)

SEV 1 — Site Down

  1. Acknowledge alert within 5 minutes
  2. Assess scope (all users vs region vs feature)
  3. Deployment-related: execute blue-green rollback
  4. Database-related: initiate point-in-time restore
  5. Communicate via status page
  6. Post-incident review within 24 hours

SEV 2 — Degraded Performance

  1. Identify bottleneck (DB query, API, leak, CPU)
  2. Scale horizontally if resource-constrained
  3. Enable circuit breakers for failing dependencies
  4. Monitor for 30 minutes after mitigation
