# Corrections Log

## Purpose
Records of errors that were made, corrected, and verified. Each entry describes what went wrong, how it was fixed, and how to prevent recurrence.

## Format
```markdown
### <YYYY-MM-DD> — <Error Summary>
- **Agent**: <which agent made the error>
- **Severity**: CRITICAL|HIGH|MEDIUM|LOW
- **Root Cause**: <what caused the error>
- **Fix**: <what was done to correct it>
- **Prevention**: <what prevents this from happening again>
- **Verified By**: <agent that confirmed the fix>
```
